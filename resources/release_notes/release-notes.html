ZHDL ZHDL_VERSION 发布说明

新增与改进

  • 按文件语言提供 Verilog / SystemVerilog 关键字补全。
  • 补全列表默认显示 keyword 类型，选中后只插入关键字。
  • 按文件维护符号缓存与工程模块索引，支持跨文件模块实例化模板及 Tab 编辑实例名和连接。
  • 补全实例的命名端口、参数与层次端口，排除已连接的端口。
  • Outline 显示信号位宽、端口类型与实例对应的模块名。
  • 更新 ZHDL 名称、扩展图标和侧栏图标。
  • 整理 README，补充本地开发步骤、配置文件位置及上游致谢。

修复

  • ctags 未解析当前文件时，关键字补全仍能正常返回。
  • 使用当前扩展上下文读取安装目录及版本信息，修复改名后的激活问题。
  • 再次打开设置菜单时，将已有设置页面显示到前台。
  • 保留 ctags 大纲，避免与 Verible 的符号列表重复显示。
  • 根据 Verible 实际能力启用后备悬停提示，修复服务启动成功但没有悬停的问题。
  • 完整构建按顺序执行，任一步失败时停止构建。

配置文件

本次更新统一 ZHDL 的 Output 通道、菜单命令和视图标识，并将索引范围及试验性实时解析移入 Open Global Settings Menu → General。英文 README 为主文档，同时提供中文版本。 临时诊断启动配置与运行时钩子已移除，本地调试使用 Run ZHDL。

全局设置保存在 ~/.zhdl_config.json，项目列表保存在 ~/.zhdl_prj.json，与原 TerosHDL 独立。可通过 Load Settings 手动导入旧全局设置。
